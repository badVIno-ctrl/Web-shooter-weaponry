# Web-shooter weaponry

**Коллекция интерактивных 3D-моделей оружия, оптики и снаряжения для веб-шутера — каждая модель в одном самодостаточном HTML-файле.**

Геометрия генерируется процедурно в коде на [three.js](https://threejs.org/): никаких `.fbx`, `.obj` и текстур — только один HTML-файл, который открывается в браузере и сразу работает. Ни сборки, ни `npm install`, ни бинарных ассетов в репозитории.

## Что внутри

- 🔧 **Процедурная геометрия** — каждая деталь собирается из примитивов и модификаторов прямо в рантайме, размеры выдержаны в реальном масштабе (bbox выводится в миллиметрах).
- 💡 **PBR-материалы и IBL** — физически корректные материалы + окружение `RoomEnvironment` для честных отражений на металле и полимере.
- 🖱 **Орбитальная камера** — `OrbitControls` с поддержкой мыши и тач-жестов, автоповорот и сброс ракурса.
- 🎬 **Анимации** — циклы выстрела и перезарядки: отход затвора, экстракция гильзы, отделение магазина, отдача.
- 🔍 **Режимы инспекции** — каркас (wireframe), подсветка узлов, габаритный бокс, опорная сетка, переключение **LOD0 / LOD1 / LOD2**.
- 📊 **HUD со статистикой** — треугольники, меши, материалы, draw calls, узлы, габариты в мм.
- ✅ **Встроенная самопроверка** — панель контроля бюджета полигонов и draw calls: сразу видно, укладывается ли модель в игровые лимиты.
- 📤 **Экспорт** — скриншот в **PNG** и выгрузка модели в **GLB** (`GLTFExporter`) для переноса в Unity, Unreal, Blender или Godot.
- 🔊 **Процедурный звук** — выстрелы и работа механики синтезируются через Web Audio API, без звуковых файлов.
- 📱 **Адаптивный интерфейс** — тёмные стеклянные панели, кнопки с тач-зоной 44 px, работает на телефоне и планшете.

> Набор инструментов немного отличается от файла к файлу: у части моделей полная отладочная панель с LOD и экспортом, у части — минимальный HUD с кнопками «Огонь» и «Перезарядка» плюс собственные фишки (см. таблицу ниже).

## Быстрый старт

### Вариант 1 — локальный сервер (рекомендуется)

```bash
git clone https://github.com/badvino-ctrl/Web-shooter-weaponry.git
cd Web-shooter-weaponry
python3 -m http.server 8000
```

Откройте <http://localhost:8000/svd.html> — или любой другой файл из каталога.

### Вариант 2 — просто открыть файл

Двойной клик по `.html` в большинстве браузеров тоже сработает. Если сцена не поднимается — браузер заблокировал ES-модули с `file://`, используйте вариант 1.

| Действие | Мышь / клавиатура | Тач |
|---|---|---|
| Вращение камеры | ЛКМ + перетаскивание | Один палец |

| Панорама | ПКМ или Shift + ЛКМ | Два пальца |
| Выстрел / перезарядка / режимы | Кнопки на панели | Тап |
